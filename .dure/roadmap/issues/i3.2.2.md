# I3.2.2 — embedded-gate validation

Harden `direction:gate-not-pass` so the embedded gate block must be a REAL `dure-gate.py` run, not a
forged paste: require the genuine output shape (`run_level_max`, `threshold`,
`per_component[].testable_signoff`, `failed`) AND internal consistency (`failed == []` when
`gate == "PASS"`). The anti-gaming property is inherited from `dure-gate.py`; this check refuses a
fabricated stub. (B1-residual from the E3.2 red-team.)
