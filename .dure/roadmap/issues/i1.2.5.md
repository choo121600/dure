# I1.2.5 — 수렴 게이트 + 게이밍 방지 가드

정량 수렴 게이트(특성④)를 구현하되, 모델이 "수렴했다"고 자기선언만으로
멈추는 게이밍을 막는다 (critique C3).

## 배경
멈춤 조건이 순수 자기평가면, 빨리 끝내려 점수를 낮출 유인이 생긴다.
→ 독립 크리틱 사인오프 + 객관 신호로 게이트를 강화한다 (spec §4.4).

## 멈춤 조건 (모두 충족)
1. 런 레벨 가중 모호성 ≤ 임계치 (config)
2. 모든 활성 컴포넌트 테스트 가능 수용기준 — **redteam-critic 사인오프 필수**
3. 미해결 블로킹 오픈 질문 0
4. 최소 1라운드 완료 AND 직전 라운드 신규 모호성 0
