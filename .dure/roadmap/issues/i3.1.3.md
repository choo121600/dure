# I3.1.3 — empty-epic signal

Surface an epic with no concrete work: its child-issue membership is empty. Because the check loads the
epic's own front matter (the backing file must exist), it is logically disjoint from doctor's
`ref:missing-backing` (which fires only when a referenced backing file is absent). Report-only; `info`.
