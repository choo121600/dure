# E3.2 — Direction-proposal layer

M3's second half: turn the survey's forward-looking signals into a **critiqued direction proposal**
that feeds `/dure:plan`. The deterministic, testable core is `scripts/dure-proposal.py`, a validator
that checks a `.dure/directions/<slug>.md` document is structurally complete and gate-ready (the
gate-readiness is the reused `dure-gate.py` PASS, embedded verbatim — never a self-declared boolean).
The `/dure:direction` orchestration skill is built on top. Spec: [specs/dure-direction.md](../../specs/dure-direction.md).
